# 🐞 BugTracker Pro

A full-stack bug tracking application built to learn professional software engineering practices.

## 🚀 Tech Stack

### Frontend
- React
- Vite
- React Router
- Axios

### Backend
- Node.js
- Express.js

### Database
- MySQL (Coming Soon)

### Authentication
- JWT (Coming Soon)

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/charan210/BugTracker-Pro.git
```

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```
